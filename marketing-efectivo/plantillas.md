# Plantillas de brief

Copia, llena y pega el brief para pedir una pieza nueva.

## Carrusel

```
Formato: carrusel 1080×1350, 6 a 8 slides (portada + contenido + slide final de marca)
Pilar: [México↔China | El chino es lógico | Ventaja del inglés | Slang | Cultura | Estudiar/viajar | Errores | Vocabulario]
Tema: [una línea]
Titular (2 a 4 palabras, palabra clave en amarillo): [ ]
Puntos (uno por slide): 
  1. [caracteres · pinyin · explicación corta]
  2. …
Pose de Pochi por slide: [stop | confusión | hype | facepalm | …]
Fotos: solo licencia abierta, con crédito
Caption: hook + desarrollo + pregunta para comentarios + puente + CTA + créditos + hashtags
Fecha programada: [ ]
Plataformas: Instagram, TikTok
```

## Reel "How to say"

```
Formato: reel 1080×1920, 11 a 15 s
Palabra: [caracteres] ([pinyin]) = [significado] · HSK [n] · reel [NNN-pinyin]
Hook: "[Significado] in Chinese"
Voz: "How to say [significado] in Mandarin?" + palabra ×2 lento + ×5 natural
Clip de Pochi: [lucha] → [victoria], corte en ~5-6 s
Consejo de tono (con analogía en español): [ ]
Combinaciones o dato cultural: [ ]
Título de TikTok (≤90): "How to say [SIGNIFICADO] in Chinese ([remate de Pochi])"
Fecha programada: [ ]
```

## Quiz HSK

```
Formato: imagen única 1080×1350
Palabra: [caracteres] ([pinyin]) · HSK [1-4]
Opciones: A [ ] · B [ ] · C [ ]
Respuesta (no va en la imagen): [letra, significado]
Foto de contexto: [ ], con crédito
Caption: "HSK [n] quiz: do you know what [字] ([pinyin]) means?" + contexto + "Comment A, B or C below and we will reveal the answer." + CTA + crédito + hashtags
Fecha programada: [ ]
Plataformas: Facebook, Instagram
```

## Prompt para pedir un plan de contenido

```
Usando la base de conocimiento de Academia Potochino (marca, audiencia, formatos, captions e inventario):
propón [N] piezas para las próximas [N] semanas.
- Mezcla los pilares y no repitas temas del inventario.
- Para cada una: formato, pilar, titular, gancho, puntos clave y fecha.
- Prioriza [objetivo: seguidores | guardados | clases de prueba].
```
